## About this tracker

Inspired by [JobRadar-AI](https://github.com/Donkey0322/JobRadar-AI): an independent Python implementation for Japan and Taiwan. No US jobs, API keys, or job database are carried over.

- Daily GitHub Actions sync from Workday career sites, community internship lists, and optional English / Japanese / Chinese web search.
- Every open Japan/Taiwan internship found is listed — no manual review step. Another country or year, and full-time roles, are left out.
- The same job found on several sites is shown once, linking to the employer's page.
- **Python 3.11+; no third-party runtime packages.** Search and AI are optional.

```bash
python3 -m tracker doctor
python3 -m unittest discover -s tests -v
python3 -m tracker sync
```

`show JOB_ID` prints a job's full evidence; `review JOB_ID rejected --reason ...` hides one you don't want, and `close` hides one that is no longer open. PhD-only titles, Japanese mentions and visa mentions are flagged, not assumed to match your eligibility. All records remain in `data/jobs.json`; `data/jobs.csv` is regenerated automatically. Applicant notes live in ignored `.local/` files and never enter the public board. A tracker cannot guarantee complete market coverage.
